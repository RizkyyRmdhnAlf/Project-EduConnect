# Project-EduConnect
EduConnect adalah platform berbasis web yang menghubungkan siswa yang membutuhkan bantuan pendidikan dengan relawan, komunitas, dan tempat belajar. Platform ini memudahkan pencarian layanan pendidikan, penyampaian kebutuhan belajar, serta penawaran bantuan secara terstruktur dan terverifikasi.

## 📖 Tentang EduConnect

**EduConnect** adalah platform berbasis web yang dirancang untuk menghubungkan masyarakat yang membutuhkan layanan pendidikan dengan relawan, komunitas, dan tempat belajar yang tersedia.

EduConnect hadir untuk membantu masyarakat menemukan informasi layanan belajar, menyampaikan kebutuhan pendidikan, serta menghubungkan kebutuhan tersebut dengan pihak yang bersedia memberikan bantuan.

Melalui satu platform, pengguna dapat mencari lokasi belajar, melihat informasi biaya dan fasilitas, mengajukan kebutuhan pendidikan, serta menawarkan bantuan secara lebih terstruktur.

EduConnect berfokus pada pemetaan layanan belajar dan kolaborasi pendidikan berbasis komunitas. Platform ini bukan Learning Management System (LMS) dan tidak menyediakan penyelenggaraan kelas daring secara penuh.

## 🎯 Tujuan Pengembangan

- Mempermudah masyarakat menemukan informasi tempat dan layanan belajar.
- Membantu siswa atau keluarga menyampaikan kebutuhan pendidikan.
- Menghubungkan relawan dan komunitas dengan kebutuhan pendidikan yang dapat dibantu.
- Memudahkan pengelola memperbarui informasi tempat belajar.
- Meningkatkan keteraturan proses verifikasi dan pemantauan bantuan.
- Menyediakan informasi aktivitas melalui dashboard sistem.

## ✨ Fitur Utama

### 1. Landing Page
- Menampilkan informasi dan pengenalan EduConnect.
- Menampilkan statistik layanan pendidikan.
- Menyediakan akses menuju direktori tempat belajar.
- Menampilkan informasi layanan belajar yang tersedia.

### 2. Direktori dan Pencarian Tempat Belajar
- Menampilkan daftar tempat belajar yang telah dipublikasikan.
- Mencari tempat belajar berdasarkan lokasi atau wilayah.
- Memfilter berdasarkan biaya, jadwal, dan fasilitas.
- Melihat detail informasi tempat belajar.
- Menampilkan lokasi tempat belajar melalui peta interaktif.

### 3. Laporan Kebutuhan Pendidikan
- Mengajukan laporan kebutuhan pendidikan.
- Menyampaikan kebutuhan seperti tutor, buku, perangkat belajar, atau fasilitas pendidikan.
- Melihat daftar laporan yang diajukan sendiri.
- Memantau status dan riwayat tindak lanjut laporan.

### 4. Penawaran Bantuan Relawan
- Melihat daftar kebutuhan pendidikan yang telah dipublikasikan.
- Mengajukan penawaran bantuan.
- Mengelola penawaran bantuan milik sendiri.
- Memperbarui status penawaran.
- Memantau perkembangan bantuan.

### 5. Pengelolaan Tempat Belajar
- Mendaftarkan tempat belajar atau perpustakaan komunitas.
- Menambahkan dan memperbarui informasi tempat belajar.
- Mengelola jadwal, biaya, dan fasilitas.
- Melihat status verifikasi tempat belajar.

### 6. Dashboard Administrator
- Melihat ringkasan aktivitas sistem.
- Mengelola akun dan peran pengguna.
- Memverifikasi tempat belajar.
- Memverifikasi laporan kebutuhan pendidikan.
- Menangani laporan konten yang tidak akurat atau berisiko.
- Memantau riwayat aktivitas penting melalui audit log.

### 7. Autentikasi dan Hak Akses
- Registrasi akun.
- Login dan logout.
- Pengelolaan profil pengguna.
- Hak akses berdasarkan peran (Role-Based Access Control/RBAC).
- Pembatasan akses data sesuai kewenangan masing-masing pengguna.

## 👥 Role dan Hak Akses Pengguna

EduConnect memiliki lima jenis pengguna dengan hak akses yang berbeda.

| Role | Hak Akses |
|---|---|
| Pengunjung | Melihat informasi umum, direktori, dan tempat belajar yang dipublikasikan. |
| Siswa/Pencari Layanan | Mencari tempat belajar, mengajukan kebutuhan pendidikan, dan memantau laporan sendiri. |
| Relawan/Komunitas | Melihat kebutuhan yang dipublikasikan, menawarkan bantuan, dan mengelola penawaran sendiri. |
| Pengelola Tempat Belajar | Mendaftarkan dan mengelola informasi tempat belajar serta melihat status verifikasi. |
| Administrator | Mengelola pengguna, memverifikasi data, menangani moderasi, dan melihat dashboard sistem. |

## 🚀 Cara Menggunakan Website

### A. Pengunjung

1. Buka halaman utama EduConnect.
2. Lihat informasi mengenai platform.
3. Buka menu direktori tempat belajar.
4. Gunakan fitur pencarian dan filter untuk menemukan layanan belajar.
5. Pilih tempat belajar untuk melihat detail informasi.
6. Lihat lokasi tempat belajar melalui peta.

Pengunjung perlu membuat akun dan login jika ingin mengirim laporan kebutuhan pendidikan atau melakukan tindakan yang memerlukan autentikasi.

### B. Siswa / Pencari Layanan

1. Buka website EduConnect.
2. Lakukan registrasi akun jika belum memiliki akun.
3. Login menggunakan akun yang telah terdaftar.
4. Masuk ke dashboard siswa.
5. Cari tempat belajar melalui direktori dan peta.
6. Jika membutuhkan bantuan pendidikan, buka menu laporan kebutuhan.
7. Isi formulir sesuai kebutuhan.
8. Kirim laporan dan tunggu proses verifikasi administrator.
9. Pantau status laporan melalui dashboard.

Siswa hanya dapat melihat laporan miliknya sendiri dan tidak dapat memverifikasi laporan yang diajukan.

### C. Relawan / Komunitas

1. Registrasi dan login sebagai relawan atau komunitas.
2. Masuk ke dashboard relawan.
3. Buka daftar kebutuhan pendidikan yang telah dipublikasikan.
4. Pilih kebutuhan yang ingin dibantu.
5. Ajukan penawaran bantuan melalui formulir.
6. Pantau status penawaran melalui dashboard.
7. Perbarui status penawaran bantuan sesuai perkembangan.

Relawan hanya dapat mengelola penawaran miliknya sendiri dan tidak dapat mengubah laporan kebutuhan milik pengguna lain.

### D. Pengelola Tempat Belajar

1. Registrasi dan login sebagai pengelola tempat belajar.
2. Masuk ke dashboard pengelola.
3. Pilih menu pengelolaan tempat belajar.
4. Tambahkan informasi tempat belajar, seperti nama, deskripsi, alamat, jadwal, biaya, dan fasilitas.
5. Kirim data untuk proses verifikasi.
6. Pantau status verifikasi melalui dashboard.
7. Perbarui informasi tempat belajar apabila terdapat perubahan.

Pengelola hanya dapat mengelola lokasi yang menjadi tanggung jawabnya dan tidak dapat menyetujui verifikasi lokasinya sendiri.

### E. Administrator

1. Login menggunakan akun administrator.
2. Masuk ke dashboard admin.
3. Periksa ringkasan lokasi belajar, laporan kebutuhan, dan penawaran bantuan.
4. Buka antrean verifikasi tempat belajar.
5. Periksa informasi yang diajukan dan tentukan keputusan verifikasi disertai alasan jika diperlukan.
6. Buka antrean laporan kebutuhan pendidikan.
7. Tinjau dan tentukan apakah laporan dapat dipublikasikan atau perlu diperbaiki/ditolak.
8. Tangani laporan konten yang tidak akurat atau berisiko.
9. Pantau aktivitas penting melalui audit log.

Setiap tindakan administratif penting harus tercatat untuk menjaga keterlacakan aktivitas sistem.

## 🔄 Alur Kerja Utama EduConnect

Berikut gambaran proses utama dalam platform:

1. Pengelola mendaftarkan tempat belajar atau siswa mengajukan kebutuhan pendidikan.
2. Administrator melakukan pemeriksaan dan verifikasi.
3. Informasi yang telah disetujui dapat dipublikasikan sesuai ketentuan.
4. Relawan atau komunitas melihat kebutuhan pendidikan yang tersedia.
5. Relawan mengajukan penawaran bantuan.
6. Status penawaran dan tindak lanjut diperbarui.
7. Pengguna yang memiliki izin dapat memantau perkembangan proses.

## 💻 Instalasi dan Menjalankan Project

Ikuti langkah berikut untuk menjalankan EduConnect di lingkungan lokal.

### 1. Clone Repository

```bash
git clone https://github.com/USERNAME/educonnect.git
```

Masuk ke direktori proyek:

```bash
cd educonnect
```

### 2. Install Dependency Laravel

```bash
composer install
```

### 3. Install Dependency Frontend

```bash
npm install
```

### 4. Konfigurasi Environment

Salin file `.env.example` menjadi `.env`.

Windows:

```bash
copy .env.example .env
```

Linux/macOS:

```bash
cp .env.example .env
```

### 5. Generate Application Key

```bash
php artisan key:generate
```

### 6. Konfigurasi Database

Buat database MySQL, kemudian sesuaikan konfigurasi pada file `.env`.

```env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=educonnect
DB_USERNAME=root
DB_PASSWORD=
```

Sesuaikan nama database, username, password, dan port dengan konfigurasi lokal masing-masing.

### 7. Jalankan Migration

```bash
php artisan migrate
```

Jika proyek menyediakan seeder untuk data awal, jalankan:

```bash
php artisan db:seed
```

### 8. Jalankan Frontend

```bash
npm run dev
```

### 9. Jalankan Laravel

Buka terminal baru dan jalankan:

```bash
php artisan serve
```

Buka alamat berikut pada browser:

```text
http://127.0.0.1:8000
```

## 🔐 Keamanan dan Privasi

EduConnect dirancang dengan memperhatikan keamanan dan privasi pengguna, antara lain:

- Kata sandi disimpan dalam bentuk hash, bukan teks biasa.
- Hak akses diperiksa berdasarkan role pengguna.
- Pengguna tidak boleh mengakses atau mengubah data pribadi milik pengguna lain tanpa kewenangan.
- Data lokasi hanya dipublikasikan setelah melalui proses verifikasi.
- Informasi pribadi, terutama milik anak di bawah umur, harus dilindungi.
- Aktivitas verifikasi dan perubahan status penting dicatat dalam audit log.
- Informasi sensitif seperti kata sandi dan token tidak dimasukkan ke audit log.
